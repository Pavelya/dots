# 0010: Our own name; "Dots" only as a descriptive word

**Date:** 2026-11-05 · **Status:** accepted

## Context

"DOTS" and "TWO DOTS" are registered US trademarks for mobile games owned by another company (per trademark search results). An app called "Dots" could be removed on their request. Background: the design investigation ([`docs/design/investigation.md`](../design/investigation.md)).

## Decision

- The game gets its own distinctive name (plan tasks B-01 to B-03).
- "dots" appears only as an ordinary word describing the game, for example in the store subtitle.

## Consequences

- The final application ID is set with the name, before the first Play upload; the POC's ID io.github.pavelya.dots stays for test builds only.
